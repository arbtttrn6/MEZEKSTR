# MEZEKSTR
MEZEKSTR, Mass Effect 1 (BioWare) extractor audio from isb files.  
Извлекатор звуков из isb файлов из Mass Effect 1 (BioWare).  
Ekstraktor zvukov iz isb fajlov iz Mass Effect 1 (BioWare).  
arbtttrn6, 2026.  
  
== RU ==  

0) Для чего?  
   0.1) Для извлечения звуков из `isb` файлов в `Mass Effect 1` (2007).  
1) Как собрать?  
   1.1) Создать папку `build`;  
   1.2) В папке `build` выполнить `cmake ..`;  
   1.3) В папке `build` выполнить `make`;  
2) Как пользоваться?  
   2.1) Для просмотра звуков в конкретном файле ввести `MEZEKSTR --list file.isb`;  
   2.2) Для извлечения всех звуков из `isb` файла ввести `MEZEKSTR --extract-all file.isb ./MyFolder`;  
   2.3) Для извлечения звука по имени из `isb` файла ввести `MEZEKSTR --extract file.isb audiofilename ./MyFolder`;  
3) Ориентиры  
   3.1) `ME3Tweaks/LegendaryExplorer`;
